**Status:** RETIRED / HISTORICAL POINTER<br>
**Retired:** 23 August 2026<br>
**Current authority:** `docs/AI-EXECUTIVE-OPERATING-MODEL.md`

The former binding contract that made Claude Desktop a permanent read-only
adversarial reviewer is superseded. Its complete historical bytes remain in Git
before the lean eight-seat operating-model adoption.

Any pre-1-August-2026 version, quotation or copied instruction from this contract
is historical even when its own text called itself `canonical`, `binding` or
`current`. Only an explicit re-ratification in the active operating model could
restore a particular rule; none restores the former permanent-review seat.

Claude Desktop is now the Delivery Executive. It owns daily dispatch, ordinary
technical decisions, routine merge/deploy and incident command within the
canonical order. It is neither Founder nor Governance.

Adversarial review is no longer a permanent seat or default phase. The sole
current review rule is the R0/R1/R2 minimum-assurance model in
`docs/AI-EXECUTIVE-OPERATING-MODEL.md`:

- R0: no adversarial review;
- R1: one targeted non-author changed-path review;
- R2: one targeted adversarial exercise only when a concrete uncertainty could
  change a reserved decision.

Do not bootstrap a session from the historical contract, require Claude Desktop
review merely because this path exists, or create a replacement standalone
review contract. This tombstone has no independent operating authority.
