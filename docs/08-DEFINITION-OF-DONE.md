# CyberMeters Definition of Done v1.0

A task is only considered complete when all of the following are true.

## Understanding

- Requirements understood
- Existing implementation reviewed
- Duplicate functionality ruled out

---

## Implementation

- Feature implemented
- Existing behaviour preserved
- Code kept simple
- Architecture respected

---

## Quality

- Code readable
- Naming consistent
- No unnecessary complexity
- No TODOs left behind

---

## Security

- Security impact reviewed
- No regressions introduced
- Tenant isolation preserved

---

## Testing

- Manual testing completed
- Edge cases verified
- Existing functionality still works

---

## Documentation

- Documentation updated where necessary
- Sprint report completed

---

## Completion

A feature is not complete because it compiles.

A feature is complete when it is secure, tested, documented, maintainable, and production ready.
